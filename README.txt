INSTRUCCIONES DE EJECUCIÓN LOCAL

1. Asegúrate de tener Python instalado en tu sistema.
2. Abre una terminal o línea de comandos y navega hasta la carpeta donde se encuentran los archivos del proyecto.
3. Instala las dependencias necesarias ejecutando el siguiente comando:
   pip install -r requirements.txt
4. Una vez instaladas las dependencias, inicia la aplicación ejecutando:
   streamlit run app.py
5. La aplicación web se abrirá automáticamente en tu navegador predeterminado.
